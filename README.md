# AI/ML Daily Tracker

A personal 16-week AI/ML learning roadmap and daily progress tracker.

## Features

- 16-week beginner-to-AI-builder roadmap
- 7 daily tasks per week
- Mark tasks complete and track overall progress
- Progress by learning phase
- Light/dark mode with browser persistence
- Responsive desktop and mobile layout
- Progress stored locally in the browser

## Roadmap

Python → Data → Machine Learning → Deep Learning → NLP → GenAI → RAG → Deployment → Capstone → Career

This repository contains the main authored source files from the Floot project. The Floot runtime/design-system components remain managed by the original project environment.
